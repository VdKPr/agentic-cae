# Data

No data files are committed to this repository. Download them locally into `data/` (ignored by git).

| Dataset | Where | What we use | Licence notes |
|---|---|---|---|
| **SimJEB** | https://simjeb.github.io (hosted on Harvard Dataverse) | `.vtk` tetrahedral meshes, `.fem` OptiStruct decks (bolt and load node sets, load values), `.csv` nodal results (displacement X/Y/Z, magnitude, von Mises for four load cases), metadata with train/test splits | Database: Open Data Commons Attribution. CAD files from the GrabCAD challenge: **non-commercial use only** |
| **DeepJEB** | https://www.narnia.ai/dataset | Bracket geometries and simulation labels for surrogate training (v2) | Check the licence before use |
| **Parametric brackets** | Generated by this repository's scripts | Design-variable studies for the lightweighting loop (v1) | Ours |
| **Analytical benchmarks** | Defined in code | Verification gate and regression tests | — |

Please cite SimJEB (Whalen, Beyene & Mueller, *Computer Graphics Forum* 2021) and DeepJEB (Hong et al., 2024) if you use them.

**Rule:** no proprietary or employer data, ever.
